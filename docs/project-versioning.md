# 项目版本规则

当前版本：`1.3.0`

状态：可用版本（production）

## 语义化版本

- `1.0.0`：当前项目的第一个可用版本。
- `1.1.0`：作品推荐拆分为独立页面，新增前五部大图轮播，并修复推荐封面加载状态。
- `1.1.1`：修正三套主题下推荐页的背景继承与轮播评分样式，压缩桌面首屏布局，让轮播图进入页面时完整可见。
- `1.1.2`：排除与个人历史别名或季度元数据匹配的已收录推荐，修正轮播评分牌对齐，并为作品简介增加可靠回退读取。
- `1.1.3`：新增按开播时间与口味匹配计算的新番推荐子模块，并改为仅轮播当前项主动读取简介、列表卡片悬浮时按需展开完整简介。
- `1.1.4`：改为向页面中心侧向展开推荐卡片详情，面板高度与卡片一致且内部独立滚动，并补充 Bangumi 评分、排名、开播信息、标签与推荐依据；窄屏自动使用下方面板。
- `1.1.5`：移除推荐页的口味模式徽标，将推荐方式切换移动到原左侧主位，并将轮播标题从“本周焦点”调整为“为你精选”。
- `1.1.6`：将跨站索引 ID 冲突从阻断部署的错误降级为构建警告，保留源数据并继续生成站点。
- `1.2.0`：油猴脚本扩展到所有 HTTP/HTTPS 页面；支持站点保留右下角悬浮入口，其他站点使用右下角贴边隐藏入口并延迟索引加载，同时保证面板在失焦和网页全屏切换后维持展开状态。
- `1.2.1`：压缩侧边入口尺寸；面板在点击外部、窗口失焦和视频全屏时自动收起，并在全屏期间隐藏全部脚本控件。
- `1.3.0`：油猴面板打开时优先恢复当前页面草稿，否则载入最近保存的未同步番剧、评分和短评。
- 新增用户可感知的功能、模块或重要能力：升级次版本号，例如 `1.0.0` → `1.1.0`。
- Bug 修复、视觉调整、文案调整、性能优化和兼容性修复：升级补丁版本号，例如 `1.0.0` → `1.0.1`。
- 主版本号只在明确要求进行大版本更新时升级。没有单独说明时，不升级主版本号。

## 版本来源

- `package.json` 的 `version` 是构建生态使用的版本。
- 根目录 `VERSION` 是项目版本的纯文本声明。
- `scripts/project-version.mjs` 向站点构建提供版本号。
- 页面 `<meta name="myanimelife-project-version">` 和页脚会显示当前项目版本。

每次正式版本更新时，上述版本值必须同步更新。算法文档使用不带独立发布版本的文件名，内容随整个项目版本维护。
